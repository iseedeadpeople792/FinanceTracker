# 💰 Finance Tracker

Адаптивное веб-приложение для учёта личных доходов и расходов.**

Finance Tracker — учебный проект, созданный с использованием HTML, CSS и JavaScript. Приложение помогает вести учёт финансовых операций, просматривать баланс и фильтровать историю записей.

## ✨ Возможности

- ➕ Добавление доходов и расходов.
- 📊 Автоматический расчёт баланса, общей суммы доходов и расходов.
- 🗂️ Категории финансовых операций.
- 📅 Указание даты и комментария для каждой записи.
- 🔎 Поиск по истории операций.
- 🧰 Фильтрация по типу операции и категории.
- 🗑️ Удаление записей с подтверждением.
- 💾 Сохранение данных в браузере с помощью `localStorage`.
- ✅ Проверка введённых данных.
- 📱 Адаптивный интерфейс для компьютеров и мобильных устройств.

## 🛠️ Технологии

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## 🚀 Запуск проекта

1. Скачайте или клонируйте репозиторий.
2. Откройте папку проекта.
3. Запустите файл `index.html` в браузере.

Сервер и установка сторонних библиотек не требуются.

## 📁 Структура проекта

```text
FinanceTracker/
├── index.html
├── style.css
├── script.js
└── README.md
```

## 💾 Хранение данных

Данные сохраняются локально в браузере с помощью `localStorage`. Они не отправляются на сервер. При использовании другого браузера или устройства записи автоматически не переносятся.

## ⚠️ Ограничения

Это учебное приложение. Оно не подключается к банковским счетам, не обрабатывает реальные платежи и не заменяет профессиональные финансовые сервисы.

# 💰 Finance Tracker

**A responsive web application for tracking personal income and expenses.**

Finance Tracker is a learning project built with HTML, CSS, and JavaScript. It helps users manage financial transactions, monitor their balance, and filter transaction history.

## ✨ Features

- ➕ Add income and expense transactions.
- 📊 Automatically calculate balance, total income, and total expenses.
- 🗂️ Categorize financial transactions.
- 📅 Add dates and notes to transactions.
- 🔎 Search transaction history.
- 🧰 Filter transactions by type and category.
- 🗑️ Delete records with confirmation.
- 💾 Save data in the browser using `localStorage`.
- ✅ Validate user input.
- 📱 Responsive interface for desktop and mobile devices.

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## 🚀 Getting Started

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.

No server setup or third-party libraries are required.

## 📁 Project Structure

```text
FinanceTracker/
├── index.html
├── style.css
├── script.js
└── README.md
```

## 💾 Data Storage

Transaction data is stored locally in the browser using `localStorage`. It is not sent to a server. Data is not automatically synchronized across different browsers or devices.

## ⚠️ Limitations

This is an educational project. It does not connect to bank accounts, process real payments, or replace professional financial services.
